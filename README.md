# GovDesk

Projeto da Semana 1: esqueleto de uma aplicação Flask para gestão de chamados de TI.

## Como executar

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Acesse `http://localhost:8080` no navegador.

## Estrutura

```text
gestao-ti/
├── app.py
├── requirements.txt
├── README.md
└── templates/
```
